# 🐍 Atividades - 1º Semestre de Ciência da Computação

Este repositório reúne as atividades e projetos desenvolvidos durante o meu primeiro semestre da faculdade de Ciência da Computação.

Durante este semestre, trabalhamos principalmente com a linguagem **Python**, desenvolvendo exercícios e projetos para colocar em prática os conceitos fundamentais de programação.

Também utilizamos a biblioteca **Turtle**, explorando programação gráfica e desenvolvendo desenhos e projetos visuais por meio de código.

## 📚 Conteúdos trabalhados

Ao longo do semestre, foram abordados conceitos fundamentais de programação, incluindo:

* Variáveis e tipos de dados
* Operadores e expressões
* Estruturas condicionais
* Estruturas de repetição
* Listas e estruturas de dados
* Funções
* Entrada e saída de informações
* Lógica de programação
* Organização e estruturação de códigos
* Desenvolvimento de projetos em Python
* Programação gráfica com Turtle
* Criação de desenhos utilizando código

## 🐢 Python Turtle

A biblioteca **Turtle** foi utilizada para introduzir conceitos de programação gráfica de maneira prática e visual.

Com ela, desenvolvemos desenhos, formas geométricas e diferentes projetos utilizando comandos em Python para controlar uma "tartaruga" na tela.

Alguns dos conceitos trabalhados incluem:

* Movimentação
* Rotação
* Coordenadas
* Cores
* Formas geométricas
* Laços de repetição
* Funções
* Padrões gráficos
* Automação de desenhos

## 🚀 Projetos e atividades

As pastas e arquivos deste repositório representam atividades realizadas durante as aulas e exercícios propostos ao longo do semestre.

Cada projeto teve como objetivo aplicar, de forma prática, os conceitos aprendidos durante a disciplina.

Entre as atividades desenvolvidas estão:

* Exercícios de lógica de programação
* Programas interativos
* Manipulação de dados
* Estruturas condicionais e de repetição
* Funções
* Projetos utilizando Python Turtle
* Desenhos e formas geométricas gerados por código
* Projetos que combinam diferentes conceitos de programação

## 🎯 Objetivo

O objetivo deste repositório é registrar minha evolução durante o primeiro semestre da graduação e reunir os projetos desenvolvidos como parte do processo de aprendizagem.

Além de servir como registro acadêmico, este repositório representa uma parte da minha evolução na programação e na construção da minha base como estudante de Ciência da Computação.

## 📈 Evolução

Este é apenas o começo.

Os projetos apresentados aqui representam os primeiros passos no desenvolvimento da minha lógica de programação e na compreensão dos fundamentos da computação.

Durante este primeiro semestre, o foco esteve na construção de uma base sólida utilizando **Python**, desde conceitos básicos de programação até projetos gráficos utilizando **Turtle**.
